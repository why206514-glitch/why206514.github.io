Agent 多通道部署日

🧠 今日技法

Agent Skill Orchestration Multi-Channel Deployment OAuth Device Flow Capability Packaging Rapid Validation DevOps for Agent

💡 技法释义

  • Skill Orchestration — 给同一个 Agent 安装多个可复用技能模块（QQ频道、视觉识图、微信问答），如同给操作系统装驱动
  • Multi-Channel Deployment — 微信走 Flask+ngrok，QQ 走官方 CLI+OAuth，同一 AI 后端服务多平台
  • OAuth Device Flow — 扫码登录 CLI 是标准设备授权流程，IoT 设备和 CLI 工具通用
  • Capability Packaging — 自建 vision skill，把 Python 脚本+模型 API 封装为标准 SKILL.md
  • Rapid Validation — 每完成一步立刻测试，不攒到最后，DevOps 思维
  • DevOps for Agent — 健康检查 cron、日志 wrapper、管理面板 status.sh

⚡ 下次如何更快

  • 一开始列出能力清单，批量安装，而非逐个触发
  • 部署服务时同步加监控，避免事后补救
  • 多用快捷命令（如 search-and-join）减少步数

🔧 今日可优化

  • QQ 频道与微信后端未统一 AI 问答能力
  • API key 散落在 3 个文件，建议统一管理
  • wechat_bot 缺乏持久化对话上下文

📈 成果

微信bot升级为AI问答助手 QQ频道接入+测试通过 视觉识图Skill上线 健康监控+日志+面板 每日复盘自动化
